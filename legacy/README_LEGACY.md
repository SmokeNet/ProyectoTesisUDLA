# Legacy — Proyecto V1 histórico

Esta carpeta queda reservada para conservar el material histórico de la V1 del proyecto.

## Advertencia de uso

El contenido legacy:

- no representa la línea base oficial V2;
- no debe usarse como evidencia de la nueva versión sin revisión;
- no debe presentarse como capacidad actual si no fue revalidado;
- se conserva por trazabilidad histórica, auditoría y aprendizaje técnico.

## Propósito

La V1 puede contener código, documentación, evidencias, pruebas, scripts y decisiones útiles como antecedentes. Sin embargo, la V2 debe reconstruirse gradualmente y solo incorporar elementos que cumplan requisitos, diseño, implementación, prueba, evidencia, documentación y trazabilidad.

## Movimiento de archivos

El traslado físico de material a `legacy/proyecto-v1/` requiere aprobación humana previa, porque implica reorganizar de forma masiva el repositorio.

La aprobación humana para mover la V1 fue otorgada y el material histórico quedó alojado en `legacy/proyecto-v1/`.

La V2 visible queda separada en la raíz `v2/`.
