# Documentación SGDP del proyecto

Esta carpeta se prepara para organizar la documentación oficial de la reconstrucción V2 según la estructura SGDP.

## Estructura

- `00-blueprints/`: blueprints y definiciones estratégicas.
- `01-documentos-rectores/`: documentos rectores y línea base.
- `02-estandares/`: estándares de nomenclatura, versionado y trazabilidad.
- `03-requisitos/`: requisitos funcionales, no funcionales y de seguridad.
- `04-arquitectura/`: arquitectura, diagramas y decisiones técnicas.
- `05-pruebas/`: planes, casos y resultados de pruebas.
- `06-evidencias/`: evidencias controladas y hashes.
- `07-manuales/`: manuales de operación, despliegue y demo.
- `08-informe-defensa/`: material para informe y defensa.
- `09-gestion/`: planificación, riesgos, cambios y seguimiento.

## Regla

No se deben inventar documentos completos solo para llenar carpetas. Cada artefacto debe crearse cuando exista contenido verificable, responsable, versión y trazabilidad.
