# Checklist de entrada de componentes a V2

Un componente técnico solo puede ingresar a la V2 oficial si cumple todos los criterios siguientes.

| Criterio | Pregunta de control | Estado |
|---|---|---|
| Requisito | ¿Existe un requisito identificado y codificado? | Pendiente |
| Diseño | ¿Existe diseño técnico documentado? | Pendiente |
| Implementación | ¿El componente está implementado sin depender de supuestos no demostrados? | Pendiente |
| Prueba | ¿Existe prueba automatizada o caso de prueba controlado? | Pendiente |
| Evidencia | ¿Genera o tiene evidencia con hash y trazabilidad EVD? | Pendiente |
| Documentación | ¿Está explicado su alcance, uso y límites? | Pendiente |
| Trazabilidad | ¿Está vinculado a REQ, TEST/CP, EVD y documentación SGDP? | Pendiente |
| Seguridad | ¿Evita acciones destructivas o irreversibles? | Pendiente |
| Revalidación | ¿Confirma el resultado después de actuar? | Pendiente |
| Escalamiento | ¿Escala cuando no es seguro remediar? | Pendiente |

## Regla de decisión

Si un componente falla un criterio, se conserva como candidato o antecedente histórico, pero no se presenta como capacidad oficial V2.
